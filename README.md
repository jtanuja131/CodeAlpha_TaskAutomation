# CodeAlpha Task Automation

This project is developed as part of my CodeAlpha Python Programming Internship.

## Project: Task Automation with Python

This Python program automates the process of creating a text file and writing user-provided content into it.

## Features
- Takes file name from the user
- Takes content from the user
- Automatically creates the file
- Writes the given content into the file
- Checks whether the file was created successfully

## Technologies Used
- Python
- File Handling
- OS Module

## How to Run
Run the `task_automation.py` file using a Python interpreter.
